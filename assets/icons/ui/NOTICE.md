# assets/icons/ui/* —— 界面自绘小图标

这里的图标有两条纪律(与 `assets/icons/edition/NOTICE.md` 同一条):

1. **一律自绘或取自允许的来源**,不用 emoji、不用字体字符(用户两次点名);
2. **逐枚写清出处** —— 将来谁问"这枚哪来的"都能查到。

取图接口有两处,口径一致(编译期宏 / 环境变量 / exe 旁的 `assets/icons/<dir>` /
`SXCL_UI_BLOCK_DIR` 的兄弟目录):
- `src/ui/ui_icons.*` —— 警示三角、叉号(老那套:文件里写 `currentColor`,读进来按令牌替换);
- `src/ui/icon_select_button.*` —— "图标当选项"的按钮(`setIconDir("ui")` 指到本目录),
  **单色线稿**在渲染后用 alpha 蒙版按主题令牌现染(`CompositionMode_SourceIn`),
  所以源文件里写死 `#000000` 只是"不透明"的意思。**微软 LOGO 例外:它保留官方四色**
  (`setMonochrome(false)`,默认就是关的)。

## microsoft.svg —— 正版(主页账号卡右上角两枚选项之一)

- 自绘:23x23 viewBox,四个 11x11 方块(间隙 1),位置/配色按公开的微软四方块标识
  (左上 `#F25022`、右上 `#7FBA00`、左下 `#00A4EF`、右下 `#FFB900`);
- 为什么自绘:官方品牌资产包需要注册下载,而**四色方块本身就是几何图形**,自己画几何完全等价,
  也不引入任何第三方文件(§9 的取舍:不为了一个标识引依赖);
- 授权/商标:微软标识是 Microsoft 的商标,本仓库只把它当作"这是正版(微软账户)登录"的指认标识,
  不宣称任何关联、不用于再分发;界面里它只在**正版**那一枚按钮上出现;
- 界面上**绝不许把它染成单色**(识别度就在这四色上)—— 验收脚本 `tools/ui_home_layout.ps1`
  按 #F25022 / #7FBA00 / #00A4EF / #FFB900 四色像素计数 > 0 来钉这一条。

## disconnected.svg —— 离线(主页账号卡右上角两枚选项之二)

- 自绘:24x24 viewBox,两节**断开的链环** + 一道斜杠(`fill=none`、`stroke-width=1.8`、圆头);
- 单色线稿:未选中染 `textSecondary`,选中染 `accent`(主题令牌,绘制时现取)。

## mod.svg —— 模组(下载页左栏第二格 / 模组页)

- 自绘:24x24 viewBox,一枚**扩展模块芯片**(方形本体 + 四边引脚),单色线稿;
- 为什么换:以前那一格用的是 PCL 的拼图块(assets/icons/pcl/mod.svg,index.tsv:15)。用户
  2026-09-27「Mod 和光影的图标赶紧找东西替代上,别就麦块版本一个草方块」—— 换一枚语义不同、
  16 逻辑像素下也认得出的自绘图形(拼图块与 PCL 那套太像,窄栏里也糊成一团);
- 界面里按**主题令牌**现染(未选中 textSecondary、选中/悬停走 accent),颜色不在文件里写死。

## shader.svg —— 光影(下载页左栏第三格 / 光影页)

- 自绘:24x24 viewBox,一个**左明右暗的对比圆**(外圈描边 + 右半实心),单色线稿;
- 为什么换:同一条点名。以前那一格是 PCL 的「光影包」图标(index.tsv:19),16px 下细节糊掉;
  对比圆在 16px 下仍然清楚,语义直给(左明右暗 = 光影);
- 着色同上:主题令牌现染。
