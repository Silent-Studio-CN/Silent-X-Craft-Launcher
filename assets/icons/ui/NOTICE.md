# assets/icons/ui/* —— 新界面(ui2, docs/27 M2)用到的图标

这里的图标有两条纪律(与 `assets/icons/edition/NOTICE.md` 同一条):

1. **一律自绘或取自允许的来源**,不用 emoji、不用字体字符(用户两次点名);
2. **逐枚写清出处** —— 将来谁问"这枚哪来的"都能查到。

取图接口是 `src/ui/ui2/icons.*`(`SXCL_UI2_ICON_DIR` 编译期指向本目录,打包后回退 exe 旁的
`assets/icons/ui`)。**单色线稿**在渲染后用 alpha 蒙版**按主题令牌现染**
(`QPixmap` + `CompositionMode_SourceIn`),所以源文件里的颜色不参与显示 ——
这也是为什么它们写死 `#000000`:那只是"不透明"的意思。**微软 LOGO 例外**:它保留官方四色。

## microsoft.svg —— 正版(玩家卡右上角两枚图标之一)

- 自绘:23x23 viewBox,四个 11x11 方块(间隙 1),位置/配色按公开的微软四方块标识
  (左上 `#F25022`、右上 `#7FBA00`、左下 `#00A4EF`、右下 `#FFB900`);
- 为什么自绘:官方品牌资产包需要注册下载,而**四色方块本身就是几何图形**,自己画几何完全等价,
  也不引入任何第三方文件(§9 的取舍:不为了一个标识引依赖);
- 授权/商标:微软标识是 Microsoft 的商标,本仓库只把它当作"这是正版(微软账户)登录"的指认标识,
  不宣称任何关联、不用于再分发;界面里它只在**正版**那一枚按钮上出现。

## disconnected.svg —— 离线(玩家卡右上角两枚图标之二)

- 自绘:24x24 viewBox,两节**断开的链环** + 一道斜杠(`fill=none`、`stroke-width=1.8`、圆头);
- 单色线稿:未选中时染 `text2`(次要文字色),选中时染 `accent`(主题令牌)。

## 实测(验收)

`tools/ui2_home.ps1` 会按控件矩形扫像素,断言:
- 四枚图标(微软 LOGO / 断线 / 换皮肤 / 切换账号 / 更改名字)在屏幕上**不是空白**(图标盒内
  与卡片底色不同的像素数 > 阈值);
- **当前态高亮**:选中那一枚的**外框 4 逻辑像素**带里有 accent 像素(蓝主导),另一枚 **0 个**;
  点另一枚 -> 高亮转移 + `game.edition` 落盘。
