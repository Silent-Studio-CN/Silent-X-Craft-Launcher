# 27 UI 重写方案（2026-09-26 定稿，用户口径：完全不同的观感 + 好看 / 有互动 / 直观 / 现代）

> 备份点：`ui-0.2.0-before-rewrite` 标签 + `backup/ui-0.2.0-before-rewrite` 分支 +
> `D:\SilentStudio\backup-sxcl-ui-0.2.0-*.zip`。核心/服务层（下载引擎、安装器、补全、隔离、取证）
> **一行不动**，它们已经是干净的 C 层；这次只换界面这一层。

## 0 为什么是重写而不是继续修

老界面是三件事的必然结果，改不完：

1. **每页手搓控件**（`settings_page.cpp` 15 万字节，几千行手工布局）→ 间距/对齐一处一个样；
2. **构造期把颜色烤死**（`setStyleSheet(令牌拼出来的串)`）→ 换主题必出事故（浅色半套 / 副标题被挤 / 左边字消失，三次都是我踩的）；
3. **页面直接调网络与文件**（版本页在 GUI 线程上同步请求清单）→ "未响应"（实测两次各 ≈2.3 秒）。

新界面把这三条变成**结构上做不到**。

## 1 视觉语言（"好看"的可执行定义）

- **一个底色，两层浮起**：`bg`（窗口）/ `surface`（卡片，圆角 12）/ `surfaceHover`；**不再用 1px 描边画卡片**，改用极轻的阴影 + 亮度差（现代感的来源）。
- **强调色只出现在"能动手的地方"**：主按钮、选中指示、进度、开关。装饰不用强调色。
- **字号只有五档**：32 / 20 / 15 / 13 / 11（显示 / 页标题 / 小标题 / 正文 / 注释），行高 = 字号 ×1.5。
- **圆角只有三档**：12（卡片）/ 10（按钮、输入）/ 6（小标签）。
- **间距只有四档**：4 / 8 / 16 / 24；页面外边距固定 24。
- **一条 12px 的脏活线**：所有"内部信息"（URL / 路径 / 键名 / 版本号 / 日志）只在折叠区里出现，主界面一个字都不露。

## 2 布局外壳（侧栏问题从此不可能出现）

```
┌──────────────────────────────────────────────────────────┐
│ 标题栏（可拖拽；左上：返回/汉堡；右：最小化 最大化 关闭）    │
├──────┬───────────────┬───────────────────────────────────┤
│ 主导 │ 子栏（可选）   │ 内容区（可滚动，只有**竖向**条）    │
│ 航   │ = 外壳的槽     │                                   │
└──────┴───────────────┴───────────────────────────────────┘
```

- 主导航与子栏都是**外壳的槽**，不是页面里的两列 → "侧1/侧2 中间那道缝""子栏被标题压下去"结构上不可能；
- 主导航 64（图标+文字）/ 折叠 48；子栏 240 / 折叠 48；两者**同一套折叠动画**（220ms OutCubic）；
- 内容区标题属于**外壳**（在内容区顶部，与子栏无关），所以子栏从顶格开始。

## 3 页面与组件（复用清单，页面里只写"数据"）

| 组件 | 用途 | 交互 |
| --- | --- | --- |
| `HeroCard` | 主页：当前版本 + 启动 | 单击启动；悬停出齿轮（版本设置） |
| `SkinAvatar` | 玩家头像（正版皮肤 / 离线首字母） | 点开账户菜单 |
| `VersionRow` | 版本行 | **单击=选中**，悬停出齿轮，双击=直接启动 |
| `CardList` | 设置/下载/MOD 列表 | 键盘可达、上下键选择、回车确认 |
| `Toast` | 顶部/四角通知 | 六位置可设；3 秒自动收，悬停暂停 |
| `StepBar` | 安装/启动阶段 | 阶段可点开看细节（默认折叠） |
| `EmptyState` | 空列表/无网络 | 一句话 + 一个按钮，绝不写内部原因 |

页面只声明**数据与槽**（标题、卡片列表、动作），布局与样式由渲染器给。

## 4 互动与动效（"有互动"的可执行定义）

- **一切过渡 150–220ms**，`OutCubic`；不用弹跳、不用缩放超过 1.02；
- **悬停必有反馈**（背景提亮一档 + 出现该行独有的动作）；
- **键盘可达**：Tab 顺序 = 视觉顺序，Esc 关闭浮层，回车触发主动作；
- **页面切换**：内容区 120ms 淡入 + 8px 上移（不做左右滑，避免"拖动感"）；
- **危险动作**（删除/覆盖）**二次确认**，且默认焦点在"取消"。

## 5 现代感的具体做法（不靠花哨）

- 卡片用"亮度差 + 大圆角 + 内容留白"，**不用描边和分割线**；
- 头像/图标用**自绘 SVG**（现有 `assets/icons` 已够），绝不 emoji；
- 状态用**颜色 + 图标 + 文字**三件套（色盲友好），失败态用 `danger`，警告用 `warning`；
- 数字/时间右对齐等宽，标题左对齐；**一行最多一个强调色块**。

## 6 工程结构（让上面这些落得下去）

```
src/ui2/                       ← 新界面，老界面 src/ui 原样保留直到迁移完
  shell/     外壳（标题栏 / 主导航 / 子栏 / 内容区 / 折叠动画）
  theme/     令牌表 + QSS 生成 + restyle 注册表（换主题只跑这一趟）
  task/      任务原语：Task::net / Task::fs，结果由框架回 GUI 线程
  render/    声明式渲染器：spec -> QWidget
  pages/     每页只有 spec + 少量事件回调
  widgets/   HeroCard / VersionRow / Toast / StepBar / EmptyState …
```

**规则（用 CI 守，不靠记性）**：

1. `pages/**` 不许出现 `setStyleSheet`、`QNetwork`、`QFile`、`QThread`；
2. 可见字符串必须来自 `lang_table.inc`，且 **lint 禁止** 出现 `http` `docs/` `SXCL_` `:\Users\` `PCL`；
3. 布局断言：`SXCL_UI_DUMP` 跑三条路由 × 三种窗口尺寸（1000×700 / 1280×800 / 900×600），
   断言"无横向条 + 关键控件坐标在容差内"；
4. 截图用 `sic` 做几何与配色的冒烟比对。
